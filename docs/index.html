XCP-ng for VMware Engineers: Virtual Lab

A small lesson for vSphere engineers moving to the Vates stack (XCP-ng + Xen Orchestra). Install a host, log in over SSH, then resolve six common support cases with the same commands you would run on a real host. Each case maps to its VMware twin and links to the official Vates / XCP-ng documentation. Nothing here touches a real system.

SimulationModelled on XCP-ng 8.3 LTS
Read this once. These screens are reconstructions made from public documentation, not captures of a real host, and the log wording is illustrative. Use the lab to learn the flow and the commands, then confirm each command with xe help <command> on a real lab host before using it in production. Source and lesson notes: GitHub repository.
